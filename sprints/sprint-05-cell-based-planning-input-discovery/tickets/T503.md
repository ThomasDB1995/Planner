# T503 - Scanbaarheid, QA En Sprint Closure

## Doel

Controleer of de cell-based planning slice bruikbaar en klein is gebleven, en sluit Sprint 05 documentair correct af.

## Context

Sprint 05 mag alleen de weekplanning UX dichter naar celgebaseerde invoer brengen. Het succescriterium is minder invoerfrictie en betere dagelijkse scanbaarheid, niet een volledig nieuw planningsysteem.

## Scope

- handmatige UX-check op scanbaarheid;
- regressiecheck op resource zoeken/filteren;
- regressiecheck op conflictmeldingen;
- build uitvoeren indien code is gewijzigd;
- QA-document bijwerken;
- `PROJECT_STATE.md` bijwerken;
- open beslissingen vastleggen.

## Buiten Scope

- nieuwe features na QA toevoegen;
- drag/drop alsnog introduceren;
- materialen of transportmiddelen bouwen;
- database/import/CRUD toevoegen;
- performance- of schaalbaarheidsoptimalisaties.

## Verwachte Bestanden

- `sprints/sprint-05-cell-based-planning-input-discovery/QA.md`
- `PROJECT_STATE.md`
- eventueel `docs/Planning_UX_Domain_Findings.md`

## Acceptance Criteria

- QA beschrijft wat is getest;
- bekende beperkingen zijn eerlijk genoteerd;
- out-of-scope controle is uitgevoerd;
- volgende stap is concreet;
- Sprint 05 blijft herkenbaar als kleine UX/discovery slice.

## Test Matrix

| Scenario | Verwacht resultaat |
| --- | --- |
| Weekplanning openen | Geen runtime errors |
| Cel selecteren | Context is duidelijk |
| Item toevoegen | Item verschijnt in juiste cel |
| Resource zoeken | ResourceSelector werkt zoals in Sprint 04 |
| Conflicten veroorzaken | ConflictSummary blijft werken |
| Meerdere items bekijken | Cellen blijven scanbaar genoeg voor discovery |

## Verificatie

- buildresultaat noteren;
- localhostresultaat noteren indien uitgevoerd;
- scopecontrole noteren;
- open UX-beslissingen bijwerken.

## Risico's

- Discovery-resultaat als definitieve UX behandelen.
- Sprint afsluiten zonder open beslissingen te bewaren.
- Te veel nieuwe wensen in closure meenemen.

## Codex Werkwijze

Geen codewijziging zonder expliciet goedgekeurd plan.
