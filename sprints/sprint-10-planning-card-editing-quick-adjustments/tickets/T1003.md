# T1003 - Lokale Updateflow En Interactieregressie

## Status

Uitgevoerd.

## Doel

Koppel de editmodus aan de lokale `planningItems` state en valideer dat selectie, delete, relocation en conflictvalidatie blijven werken.

## Scope

- update-handler in `page.tsx` toevoegen;
- exact 1 planningitem op basis van id updaten;
- item-id behouden;
- `selectedCard` logisch behouden bij directe edit;
- `activeDestinationCell` niet onbedoeld laten doorlopen na edit;
- conflictvalidatie via bestaande `findPlanningConflicts(planningItems, resources)` laten herberekenen;
- delete en relocation na edit controleren.

## Out-of-Scope

- persistence/backend/API;
- autosave;
- undo/history;
- drag/drop;
- contextmenu;
- multi-select;
- bulk edit;
- availabilityregels;
- multi-resource conflictregels.

## Files

Waarschijnlijk:

- `src/app/page.tsx`
- `src/components/planning/PlanningForm.tsx`

Alleen indien nodig:

- `src/components/planning/WeekPlanningBoard.tsx`
- `src/components/planning/PlanningCard.tsx`

## Implementatiestappen

1. Controleer directe updateflow uit T1002.
2. Controleer dat update exact 1 bestaand item op id wijzigt.
3. Controleer dat item-id en status behouden blijven.
4. Controleer dat resourceconflicten na update opnieuw zichtbaar of opgelost zijn.
5. Controleer delete na update.
6. Controleer relocation na update.
7. Controleer edit mode naar create mode via celselectie.
8. Voer alleen kleine guardrail-fix uit als overgang naar create mode ambigu of regressief blijkt.

## Acceptance Criteria

- directe edit update exact 1 bestaand item;
- item-id blijft gelijk;
- kaart blijft in juiste cel of verhuist alleen via relocation;
- conflictbadges en conflictsummary herberekenen;
- delete werkt na edit;
- relocation werkt na edit;
- create-flow blijft werken.

## Testaanpak

- taak/project wijzigen en controleren op card;
- resource wijzigen naar conflictresource en conflict controleren;
- resource wissen en conflict controleren;
- edited card verwijderen;
- edited card verplaatsen;
- nieuw item toevoegen na edit.

## Regressierisico's

- Stale selected card wanneer item niet meer bestaat.
- Destination cell blijft actief na edit en maakt move-knop onverwacht zichtbaar.
- Conflictweergave update niet omdat item buiten stateflow gewijzigd wordt.
- Edit mode naar create mode kan verwarrend zijn omdat directe edit geen cancelmoment heeft.

## Rollback

Verwijder update-handler en edit-props. Behoud bestaande create, delete en relocation-code.

## Resultaat

T1003 is uitgevoerd als regressie- en guardrailvalidatie rond directe edit mode.

Gecontroleerd:

- card openen in edit mode;
- taak/project direct wijzigen;
- resource kiezen;
- resource wissen;
- conflictvalidatie na resourcewijziging;
- delete na edit mode;
- relocation na edit mode;
- overgang edit mode naar create mode via celselectie;
- nieuwe planning toevoegen na edit mode;
- selected card blijft logisch behouden voor relocation;
- datum en werknemer blijven disabled in edit mode;
- browserconsole zonder warnings of errors.

Kleine guardrail-fix uitgevoerd:

- bij overgang van edit mode naar create mode via celselectie worden taak/project en resource leeggemaakt;
- datum en werknemer worden nog steeds geprefilld vanuit de gekozen cel;
- selected card blijft behouden zodat relocation via actieve doelcel blijft werken;
- gewone create-prefill buiten deze editovergang blijft behouden.

Validatie:

- `npm run build` geslaagd;
- localhost gecontroleerd op `http://127.0.0.1:3000`;
- directe taak/project-edit zichtbaar op card;
- resource wissen lost conflict op;
- resource opnieuw kiezen toont conflict opnieuw;
- create mode na edit toont lege taak/resource en correcte datum/werknemer-prefill;
- nieuw item toevoegen na edit werkt;
- relocation van edited card werkt;
- delete van edited/moved card werkt;
- geen browserconsole-warnings of -errors gezien.

Open UX-punten:

- Direct editing heeft nog geen undo/redo; foutieve wijziging moet handmatig teruggezet worden.
- Selected card blijft na celselectie zichtbaar terwijl formulier naar create mode gaat. Dit is nuttig voor relocation, maar vraagt blijvend duidelijke visuele scheiding tussen selected card en create-form.
- Bezette doelcel interaction ambiguity uit Sprint 08 blijft open en is niet opgelost in T1003.

Niet toegevoegd:

- drag/drop;
- persistence/backend/API;
- server-autosave;
- undo/redo;
- packages/frameworks;
- multi-resource;
- availability;
- save/cancel-flow;
- nieuwe features buiten de guardrail-fix.
