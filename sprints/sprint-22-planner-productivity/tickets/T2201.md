# T2201 - Materieel Behouden

## Doel

Maak opeenvolgende create-acties sneller wanneer planners meerdere planningitems met hetzelfde materieel aanmaken.

## Uitgevoerd

- Compacte checkbox `Materieel behouden` toegevoegd in `PlanningForm`.
- Checkbox is alleen zichtbaar in create mode.
- Checkbox staat standaard uit.
- Met checkbox uit blijft bestaand resetgedrag behouden.
- Met checkbox aan blijven geselecteerde `resourceIds` behouden na toevoegen.
- Taak/projectvelden resetten na toevoegen zoals voordien.
- Edit mode blijft ongemoeid.

## Scopebewaking

Geen persistence, backend/API, localStorage, user preferences, packages, redesign, `PlanningItem`-wijzigingen, conflictengine-wijzigingen of `resourceId/resourceIds` architectuurwijzigingen toegevoegd.

## Build

`npm run build` is geslaagd.
