# T701 - Card Selection/Focus State

## Doel

Introduceer minimale state om een planningcard afzonderlijk te kunnen selecteren, naast de bestaande geselecteerde planningcel.

## Scope

- selected-card state toevoegen;
- cardselectie doorgeven van board/cell/card naar parent state;
- bestaande `selectedCell` behouden;
- bestaande celselectie behouden;
- bestaande formulier-prefill behouden;
- geen datamodelwijziging aan `PlanningItem`.

## Out-of-Scope

- delete;
- focus UI-polishing buiten minimale selectie-indicatie;
- drag/drop;
- echte move naar andere cel;
- availability;
- multi-resource;
- weekendtoggle;
- backend/database/persistence;
- statusworkflow cleanup;
- defectstatus-focus;
- architectuuruitbreiding.

## Verwachte Files

- `src/app/page.tsx`
- `src/components/planning/WeekPlanningBoard.tsx`
- `src/components/planning/EmployeeRow.tsx`
- `src/components/planning/PlanningCell.tsx`
- `src/components/planning/PlanningCard.tsx`
- `src/components/planning/matrix.ts`

## Implementatiestappen

1. Lees Sprint 07 `SPRINT.md`.
2. Inspecteer bestaande `selectedCell` flow.
3. Definieer minimale selected-card vorm, bij voorkeur op basis van `planningItem.id`.
4. Voeg selected-card state toe in `page.tsx`.
5. Geef selected-card waarde en select-handler door naar `WeekPlanningBoard`.
6. Geef props door via `EmployeeRow` en `PlanningCell`.
7. Laat `PlanningCard` klik/keyboard-selectie doorgeven.
8. Voorkom dat cardklik onbedoeld een andere celactie triggert.
9. Behoud bestaande celklik en prefill.
10. Wijzig geen `PlanningItem` type en geen `ResourceSelector`.

## Acceptance Criteria

- gebruiker kan een individuele planningcard selecteren;
- geselecteerde card-id wordt in state bijgehouden;
- celselectie werkt nog;
- formulier-prefill vanuit geselecteerde cel werkt nog;
- selectie van een card maakt geen nieuw planningitem aan;
- selectie van een card verwijdert niets;
- geen out-of-scope functionaliteit toegevoegd.

## Testaanpak

  - planningitem toevoegen;
  - card aanklikken;
  - andere card aanklikken;

  - controleren dat prefill blijft werken.
- Build pas uitvoeren in T705.

## Regressierisico's

- Event bubbling maakt card- en celselectie ambigu.
- Cardselectie wist onbedoeld de geselecteerde cel.
- Geselecteerde card blijft verwijzen naar een item dat later verwijderd wordt.
- Keyboardinteractie op cards concurreert met celinteractie.

## Rollback

- Verwijder selected-card state uit `page.tsx`.
- Verwijder selected-card props uit board/cell/card componenten.
- Laat bestaande `selectedCell` flow ongemoeid.

## Codex-risico

Codex kan te snel een grotere interaction state machine bouwen. Houd het bij 1 selected-card id en propdoorvoer binnen bestaande componenten.
