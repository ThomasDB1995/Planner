# T404 - Seeddata Naming Alignment

Status: Voorbereid

## Doel

Hernoem seeddata export `machines` naar `resources`.

## Exacte Scope

- `machines` array hernoemen naar `resources`.
- Type import `Machine` vervangen door `Resource`.
- Seeddata inhoud gelijk houden.

## Expliciet Buiten Scope

- Seeddata inhoud uitbreiden.
- Echte import.
- Taxonomy wijzigingen.
- CRUD.

## Dependency Order

Na T401.

## Verwachte Filewijzigingen

- `src/data/seed.ts`
- `src/app/page.tsx`
- Eventuele andere imports van `machines`.

## Implementatiestappen

1. Open `src/data/seed.ts`.
2. Hernoem type import naar `Resource`.
3. Hernoem export `machines` naar `resources`.
4. Update imports in consumers.
5. Laat object ids voorlopig ongewijzigd als dat nodig is voor gedrag.
6. Run build/typecheck.

## Acceptance Criteria

- `resources` export bestaat.
- Geen actieve import van `machines` uit seeddata.
- Seeddata inhoud is functioneel gelijk.

## Regressierisico's

- Page import breekt.
- Propnamen in componenten blijven `machines` tot T406/T407.

## Testaanpak

- Build.
- Zoek op `machines` in `src` en categoriseer resterende treffers voor latere tickets.

## Rollback Considerations

- Seed export en importwijzigingen samen terugdraaien.
- Geen dubbele exports `machines` en `resources` laten bestaan tenzij tijdelijk binnen hetzelfde ticket en direct verwijderd.

## Codex-risico-inschatting

Laag tot medium. Vooral importketen-risico.
