## Go Criteria Voor Latere Implementatie

Een latere implementatieslice is alleen verantwoord als die:

- klein blijft;
- lokaal blijft;
- geen persistence toevoegt;
- availability koppelt aan `employeeId + date`;
- availability niet koppelt aan `PlanningItem`;
- geen HR-workflow bevat;
- geen conflictregels wijzigt;
- geen grouping/filtering tegelijk toevoegt;
- geen rechtenmodel introduceert;
- matrixdensity expliciet test.

## Mogelijke Volgende Implementatieslice

Voorzichtig mogelijke richting:

**Availability Type UI Prototype**

Beperkte scope:

- lokale state uitbreiden van onbeschikbaar naar typecontext;
- alleen werknemer/dag-cel;
- compacte badge/label/kleur;
- bestaande planningcards zichtbaar houden;
- planning technisch blijven toelaten;
- geen conflictregelwijziging;
- geen persistence;
- geen HR-workflow.

Deze slice mag pas starten na review en expliciete goedkeuring.

## No-Go Criteria

Geen implementatie starten wanneer het voorstel bevat:

- HR-module;
- verlofaanvragen;
- approvals;
- saldo's;
- payroll;
- contractbeheer;
- rechtenmodel;
- backend/persistence/API;
- werkbonnen of nacalculatie;
- CRM/projectbeheerflow;
- grouping/filtering samen met availability-types;
- bureauplanner als aparte view;
- tijdslotmodel als verplichting;
- drag/drop;
- packages/frameworks;
- grote planner-redesign.

## Acceptance Criteria

- alle Sprint 18 documenten bestaan;
- scope leakage is expliciet gecontroleerd;
- Go/No-Go is vastgelegd;
- grootste discovery-risico's zijn benoemd;
- geen build is uitgevoerd;
- geen code is gewijzigd;
- geen implementatie is gestart.

## Risico's

- implementatie start te snel voordat visual hierarchy gereviewd is;
- availability-types worden HR-semantiek;
- personeelstype metadata wordt rechten- of contractlogica;
- bureauplanning wordt te snel aparte view;
- densityproblemen worden pas na implementatie ontdekt.

## Resultaat

T1806 sluit Sprint 18 documentair af zodra review bevestigt dat modulegrenzen duidelijk zijn en een latere implementatieslice alleen onder strikte guardrails mag starten.
