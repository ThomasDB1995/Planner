# T2003 - Browser QA Resource Favorites

## Doel

Controleren of favorite toggling geen klikverwarring of regressie veroorzaakt in de resource selector.

## QA-resultaat

- Sterretje is duidelijk.
- Resource-selectie blijft duidelijk.
- Favoriet togglen selecteert resource niet.
- Resource selecteren togglet favoriet niet.
- Favorieten springen meteen bovenaan.
- Selector blijft compact.
- Multi-materieel selectie werkt.
- Conflictstatus blijft renderen.
