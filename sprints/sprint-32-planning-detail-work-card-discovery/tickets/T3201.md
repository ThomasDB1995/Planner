# T3201 - Work Card Read-Only Preview

## Doel

Voeg een compacte read-only werkkaartpreview toe voor de geselecteerde werknemer/dag, zodat layout, informatiehierarchie en positie in de planner gevalideerd kunnen worden zonder werkbon, editor of nieuw datamodel.

## Uitgevoerd

- `WorkCardPreview` component toegevoegd.
- Werkkaart verschijnt bij geselecteerde werknemer/dag.
- Werkkaart toont:
  - werknemer;
  - datum;
  - unieke resources voor die werknemer/dag;
  - planningitems/opdrachten voor die werknemer/dag.
- Werkkaart gebruikt alleen bestaande planningdata.
- Resources worden uniek gegroepeerd via bestaande resource ids.
- Planningitems blijven bron voor opdrachten.
- Werkkaart staat compact boven de matrix.

## Gewijzigde Bestanden

- `src/components/planning/WorkCardPreview.tsx`
- `src/app/page.tsx`

## UX-Beslissingen

- Werkkaart is plannercontext, geen werkbon.
- Matrix blijft leidend.
- Werkkaart is read-only.
- Resources tonen als compacte nummerchips.
- Opdrachten tonen als eenvoudige planningitem-titels.
- Lege dagen tonen nette lege state.
- Geen werkbon-, nacalculatie- of uitvoeringstaal.
