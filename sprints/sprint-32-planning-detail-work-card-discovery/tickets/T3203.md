# T3203 - Work Card Structured Demo

## Doel

Voeg een compacte structured demo toe aan de read-only werkkaartpreview om visueel te valideren hoe een toekomstige werkkaart dag/project/terrein-informatie kan tonen.

## Uitgevoerd

- `WorkCardPreview` uitgebreid met een gelabelde `Structuurdemo`.
- Live secties blijven zichtbaar:
  - `Materieel vandaag`;
  - `Opdrachten vandaag`.
- Demo/mock data toegevoegd voor:
  - dagmaterieel;
  - projecten;
  - terreinen;
  - instructie/materiaal/werkwijze.
- Voorbeeldprojecten:
  - `FC Oppuurs`;
  - `Daltons`.
- Voorbeeldterreinen:
  - `A-terrein`;
  - `B-terrein`.
- Voorbeeldinhoud:
  - `Doorzaaien - 200 kg graszaad - 2 richtingen`;
  - `Doorzaaien - 250 kg graszaad - 2 richtingen`.

## Gewijzigde Bestanden

- `src/components/planning/WorkCardPreview.tsx`

## UX-Beslissingen

- Matrix blijft hoofdscherm.
- Werkkaart blijft compact boven de matrix.
- Structuurdemo is expliciet herkenbaar als voorbeeld/read-only.
- Hierarchie leest van dag naar project naar terrein.
- Dagmaterieel staat apart van project/terreinregels.
- Terreinen zijn visueel onder project gegroepeerd.
- Instructie, materiaaltekst en werkwijze blijven compacte tekstregels.
