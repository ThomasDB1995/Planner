# T3202 - Lightweight WorkCard Types Discovery

## Doel

Leg een veilige TypeScript-typebasis vast voor toekomstige werkkaartontwikkeling, zonder bestaande plannerflows, `PlanningItem`, conflictvalidatie of resourcecontract te wijzigen.

## Uitgevoerd

- `WorkCard` type toegevoegd.
- `WorkCardProject` type toegevoegd.
- `WorkCardTerrain` type toegevoegd.
- `src/lib/planning/work-card.ts` toegevoegd met read-only/conceptuele helpers:
  - `WORK_CARD_SCOPE`;
  - `WorkCardSourcePlanningItem`;
  - `WorkCardIdentity`;
  - `getWorkCardKey`;
  - `isPlanningItemForWorkCard`.

## Typehiërarchie

- `employeeId`;
- `date`;

- optionele `dayNote`;
- `projects`;
- optionele `sourcePlanningItemIds`.

- `title`;
- optionele `note`;
- `sortOrder`;
- `terrains`.

Terreinniveau:

- `name`;
- optionele `instruction`;
- optionele `materialText`;
- optionele `methodText`;
- optionele `note`;
- `sortOrder`.
