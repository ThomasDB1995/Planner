# T2401 - Minimale Weeknavigatie

## Doel

Maak vorige, huidige en toekomstige werkweken zichtbaar zonder de datumgebaseerde plannerarchitectuur te wijzigen.

## Uitgevoerd

- `getWorkWeek(anchorDate)` toegevoegd.
- `getCurrentWorkWeek()` compatibel behouden.
- Week-anchor state toegevoegd in `page.tsx`.
- `WeekPlanningBoard` ontvangt actieve `days` via props.
- Navigatie toegevoegd: `Vorige week`, `Vandaag`, `Volgende week`.
- Planningitems buiten de zichtbare week blijven in state maar worden niet getoond.
- Conflictsummary volgt de zichtbare week.
- Weekwissel wist selected cell, selected card/edit state, relocation source en destination.

## Scopebewaking

Geen persistence, backend/API, database, routing redesign, employee management, week copy, templates, drag/drop, packages of grote state rewrite toegevoegd.

## Build

`npm run build` is geslaagd.
