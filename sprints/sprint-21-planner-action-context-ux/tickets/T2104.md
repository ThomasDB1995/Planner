# T2104 - Relocation Visual Context Polish

## Doel

Relocation-mode in de matrix visueel duidelijker laten aanvoelen zonder interaction complexity toe te voegen.

## Uitgevoerd

- Bezette cellen krijgen tijdens relocation-context een zachte amber-tint/rand.
- Destination cell heeft een sterkere amber-ring.
- Source card blijft herkenbaar via selected styling en subtiele accentlijn.

## Scopebewaking

Niet toegevoegd:

- nieuwe state;
- nieuwe klikzones;
- labels;
- overlays;
- extra knoppen;
- hoverlabels;
- drag/drop-taal;
- nieuwe matrixinteractie;
- matrixklikgedragwijziging.

## QA-resultaat

- Relocation-mode is visueel duidelijker.
- Bezette cellen voelen doelbaar zonder nieuwe interactie te suggereren.
- Amber leest niet als conflict/warning.
- Conflictbadges blijven belangrijker.
- Planningcards blijven dominant.
- Availability blijft ondergeschikt.
- Source card blijft herkenbaar.
- Destination cell is duidelijk.
- Het voelt niet als drag/drop.
- Create, edit, delete en relocation blijven intact.
- Bugs: nee.
