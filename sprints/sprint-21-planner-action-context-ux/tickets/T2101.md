# T2101 - Action Context Chip

## Doel

Maak create, edit en relocation context direct scanbaar in de sticky `PlanningForm`.

## Uitgevoerd

- Compacte action context chip toegevoegd.
- Context afgeleid uit bestaande state in `page.tsx`.
- `PlanningForm` toont context zonder eigen nieuwe state.

## Contexten

- `Nieuwe planning: [werknemer] - [datum]`
- `Nieuwe planning: Kies een cel`
- `Bewerken: [taak] - kies doelcel om te verplaatsen`
- `Verplaatsen: [taak] -> [werknemer] - [datum]`

## Scopebewaking

Geen nieuwe interaction mode, geen state machine, geen matrixklikwijziging en geen drag/drop-affordance toegevoegd.

Afgerond.
