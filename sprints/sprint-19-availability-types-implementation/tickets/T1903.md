# T1903 - Availability Type UX Polish

## Status

Uitgevoerd.

## Doel

Verbeter de bruikbaarheid en zichtbaarheid van typed availability zonder matrixdensity te schaden.

## Uitgevoerd

- primaire knop verduidelijkt:
  - `Niet beschikbaar` wanneer de selected cell geen availability heeft;
  - `Beschikbaar maken` wanneer de selected cell wel availability heeft.
- wissen werkt voor elk availability type via de primaire knop;
- type-select toont de huidige secundaire typekeuze;
- select wist availability niet;
- indicatorcodes aangepast naar `NB`, `REC`, `VAK`, `WV`, `ZK`;
- `getAvailabilityCellLabel(type)` toegevoegd;
- lege vacation-cellen tonen `Vakantie`;
- tooltip/title en select blijven `Jaarlijkse vakantie` tonen;
- lege availability-cellen kregen zachte volledige celkleur;
- bezette availability-cellen houden een compacte indicator.

## Visuele Regels

- geen felle kleuren;
- geen zware badges;
- geen volle saturated backgrounds;
- selected/destination state blijft zichtbaar;
- planningcards blijven dominant;
- conflictbadges blijven sterker.

- `src/app/page.tsx`;
- `src/components/planning/WeekPlanningBoard.tsx`;
- `src/components/planning/PlanningCell.tsx`.
