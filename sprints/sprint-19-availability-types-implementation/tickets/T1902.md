# T1902 - Typed Availability Rendering En Minimale Typekeuze

## Status

Uitgevoerd.

## Doel

Maak typed availability zichtbaar en wijzigbaar zonder redesign, popover library, packages of nieuwe planninglogica.

## Uitgevoerd

- `PlanningCell` ontvangt `availabilityType?: AvailabilityType`;
- boolean `isUnavailable` uit `PlanningCell` verwijderd;
- native select toegevoegd voor secundaire availability types;
- 1-click `Niet beschikbaar` knop behouden;
- availability indicators toegevoegd;
- availability rendering gekoppeld aan helperlaag.

## Typekeuze

Select/dropdown toont:

- `Recup`;
- `Jaarlijkse vakantie`;
- `Weerverlet`;
- `Ziekte`.

`Niet beschikbaar` blijft via de primaire knop lopen.
