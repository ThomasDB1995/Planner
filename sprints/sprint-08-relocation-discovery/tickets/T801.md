# T801 - Relocation Interaction Plan

## Status

Uitgevoerd als minimale interaction-discovery implementatie.

## Doel

Bepaal de kleinste interactie- en componentaanpak voor relocation via geselecteerde card, actieve doelcel en expliciete actie `Verplaats naar actieve cel`.

## Scope

- bestaande Sprint 07 interacties inspecteren;
- bron en doel expliciet benoemen:
  - bron: `selectedCard.planningItemId`;
  - doel: `selectedCell.employeeId + selectedCell.date`;
- bepalen waar de move-actie het minst storend zichtbaar wordt;
- bepalen wanneer de actie disabled of no-op is;
- regressierisico's voor celselectie, cardselectie, delete en conflictvalidatie benoemen.

## Out-of-Scope

- code wijzigen zonder goedgekeurd plan;
- drag/drop;
- packages/frameworks;
- backend/API/database/persistence;
- undo/history;
- realtime sync;
- availability;
- multi-resource;
- keyboard move;
- contextmenu;
- bulk move.

## Implementatiestappen

1. Lees Sprint 08 `SPRINT.md`.
2. Lees Sprint 07 `SPRINT.md` en `QA.md`.
3. Inspecteer de huidige selected-card en selected-cell stateflow.
4. Beschrijf de move-flow:
   - card selecteren;
   - doelcel selecteren;
   - expliciete actie uitvoeren;
   - alleen `employeeId` en/of `date` wijzigen.
5. Benoem de exacte codebestanden voor T802.
6. Benoem QA-risico's voor T803 en T804.
7. Wacht op expliciete goedkeuring voor codewijzigingen.

## Acceptance Criteria

- plan gebruikt bestaande state zoveel mogelijk;
- plan introduceert geen drag/drop of package;
- plan behoudt item-id bij verplaatsing;
- plan benoemt disabled/no-op gedrag;
- plan benoemt conflictvalidatie via bestaande `planningItems` flow;
- T802 kan direct op basis van dit plan worden uitgevoerd.

## Testaanpak

- Build uitgevoerd omdat T801 als minimale code-discovery is geimplementeerd.
- Localhost gecontroleerd op `http://127.0.0.1:3000`.

## Regressierisico's

- Actieve invoercel en doelcel worden onduidelijk.
- Move-actie voelt te makkelijk en veroorzaakt accidental moves.
- State wordt buiten `planningItems` bijgehouden.
- Verplaatsen wordt onbedoeld delete+create.

## Rollback

Omdat T801 planmatig is, rollback alleen documentatie of planwijziging indien nodig.

## Resultaat

T801 is uitgevoerd met minimale destination-state zonder echte move:

- `activeDestinationCell` state toegevoegd naast `selectedCell` en `selectedCard`;
- cellen zetten alleen een actieve doelcel wanneer er al een card geselecteerd is;
- bestaande `selectedCell` route blijft actief voor formulier-prefill;
- destination cell krijgt een minimale amberkleurige focusstijl;
- planningitems worden niet gemuteerd;
- er is geen moveknop toegevoegd;
- er is geen drag/drop, keyboard move, contextmenu, availability, multi-resource, persistence/backend/API of package toegevoegd.

Validatie:

- `npm run build` geslaagd;
- card selecteren werkt;
- actieve doelcel kan gezet worden na cardselectie;
- selected card blijft behouden;
- prefill blijft werken;
- exact 1 destination cell is actief;
- geen browserconsole-errors gezien.
